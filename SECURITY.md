# Security Policy

## Supported versions

Security fixes are applied to the latest source on `main` and, when practical,
the latest published mod releases.

## Reporting a vulnerability

Please do not disclose exploitable server, API or client/server trust issues in a
public issue. Email the maintainer at [git@kyaulabs.com](mailto:git@kyaulabs.com)
with reproduction details, affected mod/version and potential impact.

Reports are normally acknowledged within 48 hours. Third-party vulnerabilities
should also be reported to the relevant upstream project.

## Sensitive repository content

The repository must not contain server credentials, private host configuration,
save data, player identifiers or production deployment details. If any such data
is discovered in Git history, report it as a security issue so it can be rotated
and removed from history.
