# Zipline model provenance

The source scene `source/sonic_zipline_original.blend` was downloaded as
`sonic-zipline.zip` from Sketchfab. It contains the objects `ZipPostLeave`,
`ZipPostArrive`, `Trolley`, and `ZipLine`.

The project owner confirmed that this model may be redistributed in the public
AfterHours client modpack. Keep this notice with the source asset. The generated
FBX files normalize its scale and pivots but do not replace the original source.

Imported into DS_Zipline on 2026-08-31.

## Zipline Tool bolt cutters

`source/tool-boltcutter/` is **Tool - Boltcutter** by **Nikolas Gaertling**
(`@NikolasGaertling`), downloaded from:

https://sketchfab.com/3d-models/tool-boltcutter-a2c0bc1560eb491d80dce3d4818e4d58

The model is licensed under **Creative Commons Attribution 4.0 International
(CC BY 4.0)**:

https://creativecommons.org/licenses/by/4.0/

DS_Zipline combines the source FBX objects, normalizes scale/orientation with a
black-grip-center hand pivot,
converts the model to the runtime mesh payload, loads the supplied PBR textures
at runtime, and generates a derived inventory icon. The original FBX and supplied
color, normal, roughness, ambient-occlusion, and metallic maps are retained.

Imported into DS_Zipline on 2026-08-31.
