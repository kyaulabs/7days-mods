# AfterHours Web Dashboard

Full webroot replacement for the 7DTD web dashboard — the public AfterHours
community website served at https://7days.kyaulabs.com

## Layout

- `webroot/` — **the site source (canonical since 2026-08-11)** — edit here, then deploy with `./build.sh`. The live copy is `Mods/ZZ_KYAU_Dashboard/webroot/`, kept in sync by the deploy step.
  - `index.html` — single page
  - `assets/app.css` — all styling (Bebas Neue + pine/ember palette)
  - `assets/app.js` — live status polling, Leaflet fog-of-war map, mods list
  - `assets/mods.json` — GENERATED by `mod-src/build.py`, do not edit by hand
  - `downloads/AfterHours_ClientMods.zip` — GENERATED by `mod-src/build.py`, do not edit by hand
  - `assets/`, `vendor/` — media/fonts/leaflet (vendored binaries; also in the zip-excluded `downloads/` and `mods.json` are the only generated files)
- `ModInfo.xml` — dashboard mod metadata (bump `Version` on site changes)
- `tools/` — dev scripts salvaged from the original build sessions (Playwright/CDP
  headless site checks, map verification, logo/PNG helpers)
- `mod-src/build.py` — master build script: builds/deploys all mods, regenerates `mods.json` + client modpack zip
- `mod-src/KYAU_AfterHoursApi/` — C# source for the public status API
  (`GET /api/afterhours`, anonymous read-only, safe fields only). The main
  response includes online players and active loaded zombie positions for the
  live map.
  - `GET /api/afterhours/traders` — all trader POIs (name + position, derived
    from `DynamicPrefabDecorator` trader areas + prefab names)

## Deploying website changes

```bash
./build.sh
```

Syncs `webroot/` → `Mods/ZZ_KYAU_Dashboard/webroot/` (and `ModInfo.xml`), then
regenerates the generated assets. No server restart needed — the web server reads
files from disk per request.

## After changing mods (add/remove/update)

```bash
python3 /srv/7days/mod-src/build.py
```

Regenerates `mods.json` and the client modpack ZIP from the live `Mods/` folder.
Edit `CLIENT_MODS` / `HIGHLIGHT_MODS` / `HIDDEN_MODS` at the top of that script.

## After changing the API mod

```bash
/srv/7days/mod-src/KYAU_AfterHoursApi/build.sh   # builds + deploys the DLL
```

Then restart the game server. Website changes (html/css/js) need NO restart —
the web server reads them from disk per request.

## Web permissions (serveradmin.xml `<webmodules>`)

Set live via telnet (`webpermission add <module> global 2000`) — persists automatically.

- `web.map = 2000` — map tiles public (REQUIRED for the map to work)
- `webapi.Markers` — GET is 2000 by default in V3.1, but the map no longer uses
  it (MarkersMod's demo RandomMarkers were being shown; the site now renders
  traders from `/api/afterhours/traders` instead)
- `webapi.AfterHours` — defaults to 2000 (public) by design in the mod code
- Stock `ServerStats`/`ServerInfo`/`Player`/`Map` config APIs are public by default in V3.1

## Modpack versioning

`mod-src/build.py` writes a `pack` object into `mods.json`:
`version` = first 8 chars of the zip's sha1 (content-addressed — same content,
same version) and `built` = when the content last changed (carried over from
the previous mods.json when the hash matches). The site shows `v<hash> · updated
<date>` in the download panel, cache-busts the zip URL with `?v=<hash>`, and
shows a dismissible "MODPACK UPDATED" banner to returning visitors whose
localStorage `ahPackVersion` differs from the live one (first visit just
records it).

## Notes

- Map tiles only exist where players have explored (fog of war), tile coords
  are centered on world origin (can be negative). World axes: **north = +z,
  east = +x** (BlockFaces.cs); each tile PNG has north at the TOP and file
  y = floor(worldZ / tileSpan). Leaflet CRS:
  `transformation = (2^-maxZoom, 0, -2^-maxZoom, 0)`, latlng = (z, x), tileSize
  = mapBlockSize from `/api/map/config`, and the tile layer MUST flip y in
  `getTileUrl` (`coords.y = -coords.y - 1`, same as the stock web UI) or the
  map renders upside down with per-tile mirrored content and fog boundaries
  that shift between zoom levels.
- Tiles are refreshed client-side every 60 s (`refreshTiles`, `?t=`
  cache-buster) so the fog of war stays live.
- Player, trader and zombie markers each use a separate Leaflet `LayerGroup`.
  Their legend buttons add/remove those groups and gray out when disabled.
  Clicking any marker centers it and follows its updated position while its
  popup remains open; closing the popup, hiding its layer, or selecting another
  marker stops/replaces the follow target. Marker instances are updated in place
  so an open popup survives each status refresh. Zombie positions come from the
  15 s status poll with transient runtime entity IDs and are clustered in-browser
  by screen-space distance, producing numbered red circles when zoomed out.
  Only active loaded entities carrying the game's `zombie` tag are exposed
  (humanoids plus infected animals); sleepers that have not spawned are not
  revealed.
- The initial map view is centered on the centroid of AH42's five configured
  player spawn points (`x=1152`, `z=-2328`) at zoom 2. Trader loading no longer
  replaces that initial view with a world-wide trader fit.
- Leaflet's zoom control has a vertical progress meter between the +/− buttons.
  It maps the configured min/max zoom range to 0–100%, updates during zooming,
  and shows the exact percentage on hover or keyboard focus.
- The game's static file handler has no mime types for .svg/.webm/.woff2 —
  that's why the video also ships as mp4 and the logo is a PNG. Browsers
  tolerate octet-stream for fonts/video, but not for SVG <img>.
- `window.__ahMap` is exposed in app.js for debugging the map from devtools.
