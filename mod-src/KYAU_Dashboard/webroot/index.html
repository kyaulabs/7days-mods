INSTALL IN 4 STEPS

  1. Download the modpack and unzip it.
  2. Copy the Mods folder into your 7 Days to Die user folder

  3. Disable EAC: in the Steam launch options choose "Show game launcher" → uncheck "Use EasyAntiCheat". Required for mod DLLs.
  4. Launch the game → Join Game → find AfterHours or connect directly to helios.kyaulabs.com:26900
