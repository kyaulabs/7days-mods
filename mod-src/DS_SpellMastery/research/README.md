# Research: Dungeon Siege II skill system

Raw research dumps (JSON wiki exports from the Dungeon Siege fandom wiki,
fetched 2026-08-09) used to design DS Spell Mastery's skill/progression model.

- `Character_Leveling_and_Spell_Guide.*` — how DS2 handled leveling, skill
  points, spell books
- `Spells_(Dungeon_Siege_II).*` / `Spell_Book.*` — spell list + book mechanics
- `Combat_Magic.*` / `Nature_Magic.*` / `Mana.*` / `Combo.*` — skill tree branches

Reference only; PLAN.md is the authoritative design doc.
